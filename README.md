#<p align="center"> PKMNcards! Balatro mod
<img width="42" height="61.2" alt="" src="https://github.com/user-attachments/assets/c10bd3b2-1689-4249-8a77-674293175f76" /></p>



PKMNcards! - a Balatro mod that adds Pokemon Jokers alongside TCG inspired mechanics.

# Current Content
- 151+ Pokemon Jokers
- 36 'PokeMail' Jokers
- 11 Consumable 'Trainer Cards'
- 3 Seals, 1 Edition, 13 Enhancements
